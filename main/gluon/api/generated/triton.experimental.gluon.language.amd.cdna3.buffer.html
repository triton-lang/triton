triton.experimental.gluon.language.amd.cdna3.buffer

Descriptor-based buffer memory ops for CDNA3.

These access global memory through an explicit buffer resource descriptor (make_buffer_descriptor()) instead of a base pointer, with explicit bounds, a scalar offset and per-access coherence scope. The pointer-based buffer_load / buffer_store in the parent module are unchanged but will be deprecated and migrated to these ops soon.

Functions

make_buffer_descriptor

Make a buffer resource descriptor from the hardware fields the program controls.

load

Load from global memory through a buffer descriptor into registers.

store

Store a tensor to global memory through a buffer descriptor.

atomic_load

Atomically load from global memory through a buffer descriptor.

atomic_store

Atomically store to global memory through a buffer descriptor.

Classes

CachePolicy

Cache hints for gfx9 (CDNA3/CDNA4) buffer accesses.

buffer_descriptor

A buffer resource descriptor (V#), made by make_buffer_descriptor.

buffer_descriptor_type

The type of a buffer resource descriptor accessing element_ty elements.
